# Megnyerted az álomutat!

A mai óra első részében kicsit rendhagyó módon fogunk dolgozni. Első körben arra kérlek titeket, hogy alkossatok 2-3. fős csapatokat. Az óra időbeosztása nagyjából a következő lesz:

1. Ügyféligény felmérése (0-5. perc)
2. Kérdések az ügyfél felé, feladat kisebb ticketekre bontása (5-15. perc)
3. Egyeztetés az ügyféllel (15-20. perc)
4. Közös implementációs terv, hiányosságok megbeszélése (20-30. perc)
5. Önálló implementáció (30-55. perc)
6. Feladat értékelése, reflexió (55-60. perc)

Az időkeretet nyilván rugalmasan kezeljük, ez csak egy nagyjából iránymutatás, hogy mire számíthattok a mai órán.
